# Release checklist

- [ ] Every changed material claim was checked against the complete source.
- [ ] Source identity, version, publication status and corrections were rechecked.
- [ ] Source registry, evidence matrix and derivations match the pages.
- [ ] English and Czech facts, citations, units, dates and caveats agree.
- [ ] Czech terminology and prose received a human-language review.
- [ ] Structural validation and browser tests pass.
- [ ] Desktop and mobile views, interactions and language navigation were inspected.
- [ ] External source links were checked; access blocks were distinguished from dead links.
- [ ] No full texts, local paths, credentials, screenshots or internal notes are staged.
- [ ] A human maintainer approved the evidence and final wording.
- [ ] Only `site/` is configured for deployment.
- [ ] Both production URLs were checked after deployment.
