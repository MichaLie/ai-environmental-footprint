# Contributing

Corrections and well-supported updates are welcome.

Before proposing a factual change, obtain the relevant full text legally, read it in full and update the source registry and claim-evidence matrix. Keep source files outside the repository. Changes to evidence must be made in both language versions and retain the original scope, uncertainty and limitations.

For layout or accessibility changes, confirm that no factual text, number, citation or interaction has changed. Run the checks in [AGENTS.md](AGENTS.md) before opening a pull request.

Please explain what changed, which evidence was checked and any limitation that remains. Maintainer approval is required before evidence-affecting changes are published.
